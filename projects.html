المشاريع والتطبيقات الإحصائية

نماذج برمجية وإحصائية غنية تربط النظرية بالتطبيق الفعلي

1. رسم الهرم السكاني التفاعلي بلغة R

استخدام مكتبة ggplot2 لتصميم هرم سكاني مقلوب أو عالي الدقة يوضح توزيع الفئات العمرية بين الذكور والإناث:

# تحميل المكتبات المطلوبة
library(ggplot2)

# إنشاء بيانات افتراضية للهرم السكاني
age_groups <- factor(c("0-14", "15-24", "25-54", "55-64", "65+"), levels = c("0-14", "15-24", "25-54", "55-64", "65+"))
males <- c(-30, -25, -40, -15, -8)
females <- c(28, 24, 38, 16, 10)

df <- data.frame(age_groups, males, females)

# رسم الهرم السكاني
ggplot(df) +
  geom_bar(aes(x = age_groups, y = males), stat = "identity", fill = "#2563EB") +
  geom_bar(aes(x = age_groups, y = females), stat = "identity", fill = "#06B6D4") +
  coord_flip() +
  labs(title = "Population Pyramid", x = "Age Group", y = "Population Count") +
  theme_minimal()

2. مخططات ضبط الجودة (R-Charts)

تُستخدم لوحات التحكم بالإحصاء (Control Charts) لتتبع التباين والانحرافات المعيارية للعمليات مع مرور الوقت ومراقبة حد الضبط الأعلى (UCL) وحد الضبط الأدنى (LCL).

  • مراقبة ثبات تشتت العمليات.
  • التمتّع بتقييم مستمر للجودة عبر برمجيات مثل Minitab و R.

3. الاختبارات غير المعلمية (Ansari-Bradley)

يُعد اختبار **Ansari-Bradley** خياراً ممتازاً للمقارنة بين تشتت عينتين مستقلتين عندما لا تتوزع البيانات توزيعاً طبيعياً:

# تنفيذ اختبار أنساري-برادلي في R
group1 <- c(12, 15, 18, 11, 14)
group2 <- c(22, 10, 29, 31, 19)

ansari.test(group1, group2)
